# 🐍 Snake Water Gun Game

A simple command-line Snake Water Gun game built using Python.

## 🎮 About the Game

Snake Water Gun is a classic game similar to Rock Paper Scissors.

The player chooses one of three options:

- 🐍 Snake
- 💧 Water
- 🔫 Gun

The computer randomly selects one option, and the winner is decided according to the game rules.

## 📜 Game Rules

| Player | Beats |
|--------|-------|
| 🐍 Snake | 💧 Water |
| 💧 Water | 🔫 Gun |
| 🔫 Gun | 🐍 Snake |

If both choose the same option, the round is a draw.

## ✨ Features

- 🎮 User vs Computer gameplay
- 🎲 Random computer choices
- 📊 Score tracking
